# Тест-кейсы и регрессионный чек-лист

## Основные тест-кейсы

| ID | Проверка | Шаги | Ожидаемый результат |
|---|---|---|---|
| TC-01 | Открытие главной страницы | Открыть `index.html` | Страница загружается без визуально пустых блоков и ошибок сценария |
| TC-02 | Переход к кейсам | Нажать «Посмотреть кейсы» | Фокус просмотра перемещается к разделу «Кейсы» |
| TC-03 | Якорная навигация | По очереди открыть все пункты верхнего меню | Каждый пункт ведёт к правильному разделу |
| TC-04 | Внешняя ссылка GitHub | Нажать «GitHub» | Профиль `Kirill-factz` открывается в новой вкладке |
| TC-05 | Включение светлой темы | В тёмной теме нажать переключатель | Цветовая схема меняется, подпись кнопки обновляется |
| TC-06 | Сохранение темы | Выбрать тему и обновить страницу | Выбранная тема сохраняется |
| TC-07 | Первый визит без настройки | Очистить ключ темы и открыть страницу | Применяется системная цветовая схема |
| TC-08 | Клавиатурная навигация | Использовать Tab и Enter | Все ссылки и кнопка доступны, фокус хорошо виден |
| TC-09 | Skip link | Нажать Tab первым действием, активировать ссылку | Фокус переходит к основному содержимому |
| TC-10 | Мобильная ширина | Открыть страницу на ширине 360 px | Нет горизонтальной прокрутки, текст и кнопки не обрезаны |
| TC-11 | Увеличение текста | Увеличить масштаб браузера до 200% | Контент остаётся читаемым и доступным |
| TC-12 | Reduced motion | Включить системное уменьшение движения | Плавная прокрутка и переходы отключаются |

## Негативные проверки

- `localStorage` содержит неизвестное значение темы — используется системная тема;
- JavaScript отключён — основная информация и ссылки остаются доступными;
- очень длинный системный шрифт или увеличение текста не создают горизонтальную прокрутку;
- внешняя ссылка открывается безопасно с `rel="noreferrer"`.

## Регрессионный чек-лист

- [ ] Заголовок и описание страницы соответствуют вакансии
- [ ] Все четыре якоря открывают нужные секции
- [ ] Все три Markdown-кейса доступны из карточек
- [ ] Ссылка на GitHub ведёт на правильный профиль
- [ ] Светлая и тёмная темы имеют читаемый контраст
- [ ] Выбор темы сохраняется после обновления
- [ ] Кнопка темы имеет корректный `aria-label`
- [ ] Видимый фокус есть у всех интерактивных элементов
- [ ] На 360 px нет горизонтальной прокрутки
- [ ] На 200% масштабирования контент не перекрывается
- [ ] В консоли нет необработанных ошибок
