# Technical Support кейс: «Не включается тёмная тема»

## Обращение пользователя

> Нажимаю кнопку темы, но после обновления сайт снова становится светлым.

## 1. Уточнение

Для диагностики нужны:

- адрес страницы;
- браузер и его версия;
- повторяется ли проблема в приватном окне;
- меняется ли тема до обновления страницы;
- есть ли сообщения об ошибках в консоли.

## 2. Воспроизведение

1. Открыть сайт в светлой теме.
2. Нажать кнопку смены темы.
3. Убедиться, что внешний вид изменился.
4. Обновить страницу.
5. Сравнить результат с ожидаемым состоянием.

Проблема воспроизводится: после переключения в хранилище записывается неверное значение.

## 3. Локализация

- кнопка получает событие `click`;
- CSS-класс темы визуально применяется;
- ошибка возникает при проверке имени активного класса;
- в условии JavaScript используется строка `dark  -theme` с лишними пробелами;
- поэтому код выполняет неверную ветку и сохраняет `light`.

## 4. Ответ пользователю

Здравствуйте! Проблему удалось воспроизвести: тема переключается, но выбранное состояние сохраняется неправильно, поэтому после обновления возвращается светлый вариант. Причина найдена в логике переключателя. Исправление подготовлено. До обновления можно временно не перезагружать страницу после выбора темы.

## 5. Эскалация разработчику

- Компонент: theme switcher
- Влияние: пользовательская настройка не сохраняется
- Воспроизводимость: 100%
- Приоритет: High
- Техническая причина: неверная строка класса в `classList.contains()`
- Рекомендация: хранить тему как `light` / `dark`, добавить проверку после перезагрузки

## 6. Проверка исправления

- переключить тему дважды;
- обновить страницу после каждого переключения;
- закрыть и снова открыть вкладку;
- проверить поведение при пустом `localStorage`;
- проверить системную светлую и тёмную тему;
- убедиться, что `aria-label` кнопки соответствует следующему действию.

> Кейс основан на реальном дефекте старой версии этого учебного сайта.
