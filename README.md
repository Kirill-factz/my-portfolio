# Кирилл — Technical Support / Junior QA

Портфолио для поиска первой работы или стажировки в Technical Support и Manual QA.

## Что подтверждает портфолио

- техническую базу: HTML, CSS, JavaScript, Python, Kotlin, Jetpack Compose, базы данных;
- умение воспроизводить и локализовать проблему;
- оформление чек-листов, тест-кейсов и баг-репортов;
- понятную письменную коммуникацию;
- адаптивную и доступную веб-вёрстку.
